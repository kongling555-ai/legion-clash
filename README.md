# 战锤40K：军团争霸

非商业同人卡牌对战。一名玩家执掌帝国五人小队，另一名执掌混沌。回合交替，伤害、治疗、腐化、经验和胜负全部在服务端结算。

## 怎么玩

打开游戏后可以单机演练，或进入大厅创建房间。把四位房间号告诉另一台设备，对方加入后立即开战。刷新或短暂断线后，同一台设备会用原来的身份接回房间。

战斗结束可以净化或吸收混沌战利品。灰骑士只会净化。腐化到 80 会进入临界抉择，到 100 会进行忠诚试炼。堕落不可逆。

## 架构说明

这套网页直接运行在当前托管环境里，权威规则在服务端模块，房间状态写入 Postgres（预览环境会自动退到内嵌数据库）。双人同步用短轮询，足够回合制，也避免依赖一台常驻的 Socket.IO 进程。

因此没有单独的 Express 服务，也没有替你部署到 Railway。发布后的 HTTPS 地址就是两台手机应打开的同一个网址。不要相信浏览器里改出来的生命、攻击或经验，那些数值不会被服务器采用。

速度属性已配置，但第一版行动顺序固定为帝国、混沌交替，客户端不能改速度。

## 本地检查

安装依赖后执行 `npm test`、`npm run typecheck` 和 `npm run dev`。开发服务监听 8080。
